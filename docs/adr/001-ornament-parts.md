# 彩りパートを4行のバンクとして追加

基本4パートに彩り4パートを追加する。上下の操作領域を増やさないため、ジャンル見出しの横で基本／彩りを切り替える。表示だけを切り替え、全8パートの再生とミックス状態を維持する。

彩りは純粋な拍単位のイベント生成と音声出力を分離し、既存Progressionの時計・現在のコード・スウィングに従う。8パートで一つのミキサーを共有し、非表示バンクにもソロを適用する。パターン変更時はその声部の予約音を破棄し、次に予約される小節から新パターンを演奏する。停止は全声部の未来の発音も破棄する。

既存のMilkデザインを継承し、音色・パターン・M/S・音量の操作を揃える。追加の依存・保存形式・ネットワークI/Oは導入しない。
