# oto / Object System

音で遊ぶ、手のひらの道具。クリーム色のサンプラーを基準に、レトロ電卓の親しみと楽器の精度を合わせる。テック機器的な発光・過剰な数値・装飾的なラベルは加えない。

## 材料と階層

- 筐体：温かい樹脂。大きな面は線で囲わず、薄い上面ハイライトと底面の影で厚みを表す。
- 入力：音色・奏法などの選択欄はコードセルに近い明るい面と浅い影で、操作できることを示す。
- キー：操作できる要素は明るい上面と短い底面の影。選択中のパートはセカンダリー色の面に内側の影を入れ、少し沈んだ形で示す。
- 再生：アクセント色は主要操作に絞る。通常の入力欄までアクセントで塗らない。
- 進行表：読める余白を残す。セルを四方から囲まず、現在位置の面の変化で示す。

## トークン

`dist/skins.css` が外観の契約。`--oto-page` は背景、`--oto-case` と `--oto-case-low` は筐体、`--oto-key` と `--oto-key-low` はキー、`--oto-display` と `--oto-display-ink` は表示部、`--oto-accent` は主要操作、`--oto-secondary` は選択中のパート。`--oto-raised` と `--oto-recess` で凸と凹を統一する。

角丸は筐体18px、表示7px、キー7pxを基準にする。余白は4px単位を目安に、操作間隔は8〜14px。関連する操作を近づけ、パネル間にも必要以上の余白を設けない。見出しは控えめに太くし、値と音名を主役にする。外部フォント・画像素材は不要。

## スキン

- Milk：標準。乳白色のキー、濃い墨色の文字、朱色の再生キー。
- トイは白いキーに赤・青・黄を配した、おもちゃらしい配色。
- ソーダは白いキーを主役に、水色の筐体と補助キー、濃い青の再生キーを組み合わせる。
- ナチュラルとバウハウスの保存値はミルクとして表示する。

配色だけを変え、同じ操作位置・情報の順序・機能を保持する。スキンは「外観」から即時選択し、localStorageに任意の設定として保存する。保存不可でも操作は可能。

## 操作

ホバーでレイアウトを動かさない。画面全体でフォーカス時の外枠は表示しない。キーボードフォーカスは面や文字の色、入力欄の下端のアクセントなどで控えめに示す。コード入力先は背景色で示す。スライダーはつまみをアクセント色にする。押せるキーには浅い立体感を使う。設定画面はネイティブdialogを使い、Escape、フォーカス制御、閉じた際の元のボタンへの復帰に対応する。動きを減らす設定を尊重する。


ベースのフレーズに使う音は、それぞれ独立したトグルキーとして扱う。選択中は明るい面と立体感を保ち、文字色と下端のアクセントで示す。拍の位置は必ず一つを選ぶセグメントとしてまとめ、未選択の見た目と区別する。両方ともネイティブ入力を残し、キーボードと読み上げに対応する。

## メロディの探索パッド

メロディは4列×2段の8パッド。標準「音程を固定」では全体キーの1オクターブのスケールを保持し、伴奏のコード・局所転調が変わってもパッドのMIDI音程は変えない。全体キー変更時のみ配列を移調する。「ルートを追う」は従来のコード相対音選びを残す。

配色は位置でなく現在の和声上の役割に対応。構成音はセカンダリー8%、未構成のテンションはプライマリー7%をキー面へ混ぜ、度数と役割の文字を併記する。テンションを構成音が半音下から支える場合は「半音のぶつかり」と示す。これはピッチクラスによる簡易目安で、実際の音域や旋律の解決を評価するものではない。色を正解・不正解には対応させない。

右上に現在のコード名、下に最後に弾いた音の役割変化を表示。例：Eを叩いたままFmaj7→Gで「7→13」。発音はユーザーのタップ／キー操作のみ。シーケンサー録音は未実装。

メロディ欄の相棒はOtto（オットー）。見出しは「Ottoとセッション。」。両役割のパッドに同じraisedの影を使い、下段も影をクリップしない。役割は度数の下線と文字のインクでも示す。モード選択時はOttoが吹き出しで遊び方を話す。


## チェックボックス

`.oto-checkbox` はネイティブ入力を維持し、キー面・シーム・セカンダリー色で未選択／選択を表す。キーボードフォーカスは面の色で示す。


## チュートリアルのリズム表示

1小節を横軸に4拍で表示する。拍の境界は実線、8分音符の位置は濃い破線、16分音符の位置は薄い破線とする。音符の開始位置と長さを横位置と幅に対応させ、音符記号は帯の左側に置く。自由な音を選ぶ練習では、上から8分音符、16分音符、4分音符、2分音符の順に行を分け、使わない行は詰める。鍵盤の音名を指定する練習とスライドは、帯の中で音符を上、音名を下に置く。スライドは音のつながりを表示する。

帯はスキンのキー色、進行部分は黄色と控えめな内側の線を使う。スマホでも同じ時間軸と行を保ち、文字と余白を縮める。狭い画面での代替表示は検証後に決める。
